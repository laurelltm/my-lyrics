# Self-hosted fonts

Adobe Source Serif 4 (Regular, Semibold) and Source Sans 3 (Regular, Semibold), used under the included SIL Open Font License 1.1 files. Fonts are served locally; the website makes no font-service requests.

Official release sources, downloaded 17 October 2026:

- https://github.com/adobe-fonts/source-serif/tree/release/WOFF2/OTF
- https://github.com/adobe-fonts/source-sans/tree/release/WOFF2/OTF

The Semibold faces serve the website's 600 weight. Font synthesis is disabled.
