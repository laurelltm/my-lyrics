Backup and restore

Keep a transferable copy of your books, collections, settings and drafts.

  1. 1

    Create a backup

    Open Settings → Backup. Back up now creates a copy; Export file saves a .mylyrics file you can move or keep elsewhere. Browser libraries should also be backed up before site data is cleared.

  2. 2

    Use platform cloud options

    The iPhone app supports iCloud. On Android, explicitly connect Google Drive from Backup settings. Browser cloud options differ; use file export for a transferable backup.

  3. 3

    Inspect and compare

    Opening backup or restore reads the available copies and shows a loading indicator. You can cancel the inspection. Identical-content indicators ignore reading position and history.

  4. 4

    Restore deliberately

    Review the restore preview before confirming. Merge with current keeps existing content. Replace current first creates a local safety copy. Nothing is restored automatically at app startup.

Moving between platforms

The same .mylyrics backup file works on iPhone and Android. Transfer it yourself and review restoration. Cloud copies do not provide live synchronization or automatic transfer between platforms.

Import only the books

Use Library → Library menu → Import a file and choose the backup. Full backup restoration is a separate action under Settings → Backup. The legacy .mylyricsbackup format is also readable.

Example songbook file

Songbooks are simple JSON files. Here is a small example with one song from the My Lyrics guidebook.

{
  "title": "My Lyrics",
  "songs": [
    {
      "number": 1,
      "title": "Song of Creation",
      "verses": [
        {
          "number": 1,
          "sentences": [
            "This app is empty, it starts off bare,",
            "The content is yours, create if you dare."
          ]
        }
      ]
    }
  ]
}
