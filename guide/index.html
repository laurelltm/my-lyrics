Reading and navigation

The Library shows your songbooks. Open a book, then use the tabs below to move around the app.

LibrarySearchBookCollectionsSettings
  1. 1

    Open a book

    Use Library to open a songbook. Book returns to your current book.

  2. 2

    Read and move between songs

    Swipe sideways to change songs. Tap the song number to jump directly.

  3. 3

    Search for lyrics

    Search the current book or all books, then open a matching result.

  4. 4

    Use collections

    Organise songs into sections. Book and Collections keep separate reading positions.

Example songbook file

Songbooks are simple JSON files. Here is a small example with one song from the My Lyrics guidebook.

{
  "title": "My Lyrics",
  "songs": [
    {
      "number": 1,
      "title": "Song of Creation",
      "verses": [
        {
          "number": 1,
          "sentences": [
            "This app is empty, it starts off bare,",
            "The content is yours, create if you dare."
          ]
        }
      ]
    }
  ]
}
