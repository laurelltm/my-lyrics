Books and files

A book contains songs, and each song contains verses or choruses. Plain JSON is a good starting point when creating your own files.

Choose the right file

FileContainsWhere to open
.booksOne or more booksLibrary → Library menu → Import a file
.json / .zipBook content and compatible legacy archivesImport books
.collection.booksA collection, its sections and songsCollections → plus → Import collection from file
.mylyricsongOne transferable songOpen the received file and choose a collection
.mylyricsA complete backupSettings → Backup → Restore from a file

Create a JSON songbook

Start with the downloadable example. Change its book title, songs and sentences in a plain-text editor. Save it as UTF-8 JSON, then import it through the Library menu. You can share the imported book from My Lyrics to produce a .books package.

FieldTypeMeaning
titlestringBook name. A song title is optional.
songsarrayThe songs in a book.
numbernumberOptional song or verse number.
versesarrayThe parts of a song.
sentencesarray of stringsThe lines in a verse or chorus.
coverImagestringOptional base64-encoded book cover.
headingStylenumbers / titlesOptional book setting; titles adds the title below the number.

Use the app for packaged files

Book, song, collection and backup exports have different structures. Use the app’s share or export actions to create them. Renaming a file does not convert its contents.

The legacy .mylyricsbackup format remains readable. Import a backup through Library when you want only its books, or use Backup settings for a full restore.

Example songbook file

Songbooks are simple JSON files. Here is a small example with one song from the My Lyrics guidebook.

{
  "title": "My Lyrics",
  "songs": [
    {
      "number": 1,
      "title": "Song of Creation",
      "verses": [
        {
          "number": 1,
          "sentences": [
            "This app is empty, it starts off bare,",
            "The content is yours, create if you dare."
          ]
        }
      ]
    }
  ]
}
