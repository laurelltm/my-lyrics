Reading preferences

Choose a comfortable reading style for your eyes and the place where you sing.

  1. 1

    Adjust the text

    Open Settings → Text appearance. Change size, weight, alignment and line spacing. The preview shows a first-verse number so you can see the effect of the verse-number setting.

  2. 2

    Choose a theme

    Settings → Theme offers eight visual theme families. Within a family, choose light, dark or the device appearance. Warm paper and Parchment are two of the choices.

  3. 3

    Show song titles

    Press and hold a book cover and choose Show song titles. Enabled titles appear below the normal tappable song number. The title is always optional.

  4. 4

    Use full-screen reading

    Tap the lyrics to hide the top and bottom bars. Tap again or scroll to the start or end to restore them. The song heading remains visible. Turn off tap-to-full-screen in Text appearance if you prefer.

Example songbook file

Songbooks are simple JSON files. Here is a small example with one song from the My Lyrics guidebook.

{
  "title": "My Lyrics",
  "songs": [
    {
      "number": 1,
      "title": "Song of Creation",
      "verses": [
        {
          "number": 1,
          "sentences": [
            "This app is empty, it starts off bare,",
            "The content is yours, create if you dare."
          ]
        }
      ]
    }
  ]
}
