Troubleshooting and support

A few checks solve the most common issues. Keep a backup before removing the app or clearing browser data.

  1. 1

    A song is missing

    Check that the correct book has been imported. Search all books with a few words from the lyrics. Number navigation always uses the open book.

  2. 2

    A file will not open

    Save it to your device first, then select it in the app’s import flow. Check the extension below. If the file is damaged, ask the sender to share it again.

  3. 3

    The text is hard to read

    Adjust Text appearance and Theme in Settings. Try a larger size, stronger weight or a higher-contrast theme.

  4. 4

    Ask for help

    Email laurelltm@gmail.com. Describe what you were doing, the platform and the app version. Avoid sending private songbook content unless you want to include it.

Browser storage

Your web library belongs to this browser and site. Private browsing, browser cleanup or site-data removal may erase it. Export a backup before changing browsers or clearing data.

Example songbook file

Songbooks are simple JSON files. Here is a small example with one song from the My Lyrics guidebook.

{
  "title": "My Lyrics",
  "songs": [
    {
      "number": 1,
      "title": "Song of Creation",
      "verses": [
        {
          "number": 1,
          "sentences": [
            "This app is empty, it starts off bare,",
            "The content is yours, create if you dare."
          ]
        }
      ]
    }
  ]
}
