My Lyrics support

Build and test songbook files

My Lyrics renders custom songbook files on iPhone and iPad. This page explains the supported file format and links to a live browser demo.

Open live web demo Read file format guide Privacy policy

Book files

A library file uses the .zip or .books extension and contains one or more JSON songbooks. Plain JSON book files are also supported.

See the full support guide and the bundled example songbook JSON.

Live web demo

The demo page embeds the Flutter web build in an iPhone-style frame and can also be opened full screen. It is intended for quick browser testing and public documentation, while the source app remains in the Flutter repository.
